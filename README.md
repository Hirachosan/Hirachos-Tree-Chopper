

# Hiracho's Tree Chopper

A small mod that allows players to fell entire trees by chopping the same log over and over again until the whole tree comes crashing down!

To use, simply start chopping the log directly above a stump. This will transform it into a block that slowly gets chipped. as soon as youve hit it as many times as there are connected logs, all the connected logs will break!
